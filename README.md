# Data Science & Machine Learning Course

A step-by-step course in Jupyter notebooks, from Python basics to machine learning.
Each lesson explains a topic, gives working examples, practice problems with solutions, a project and a cheat sheet.

Start with **[Topic_00_All_Topics_Index.ipynb](Topic_00_All_Topics_Index.ipynb)**, the full list of every section in every lesson.
Each lesson also opens with its own clickable index.

## Requirements

Python 3 with `numpy`, `pandas`, `matplotlib`, `seaborn`, `scipy`, `scikit-learn` and `jupyter`.

## Data

Datasets used by the notebooks are in the [`data/`](data) folder:

- `winequality-red.csv` — red-wine quality (Topics 2, 4, 7, 16)
- `customer_sales_dirty.csv` / `customer_sales_clean.csv` — data-cleaning workflow (Topic 2)
- `sales_data.csv` — missing-value practice (Topic 3)
- `HR_comma_sep (1).csv` — HR employee dataset

Run notebooks from this folder so the `data/...` paths resolve.
